# Resources Page Recreation Specification

## Goal
Produce a complete written specification for recreating the current OccupiaCare Resources page exactly, without changing the site.

## What the specification will cover
1. **Page structure**
   - Shared navigation and page frame
   - Intro section with eyebrow, headline, and supporting paragraph
   - Two-column resource-card grid
   - Closing strategy-meeting call-to-action
   - Shared footer

2. **Resource inventory**
   - Record all 12 cards in their current order
   - Include each card’s reference code, icon, title, description, button label, and destination
   - Identify repeated card patterns and shared behavior

3. **Visual direction**
   - Clinical Editorial styling: bold uppercase headings, monospaced labels, warm paper background, dark ink, clinical blue accents
   - Grid borders, square card treatment, typography hierarchy, spacing, icon scale, and button styling
   - Desktop two-column behavior and mobile single-column behavior

4. **Page behavior and metadata**
   - Explain links and interaction states
   - Document the page title, description, and social metadata
   - Note image usage, accessibility labels, and responsive behavior

5. **Source map**
   - Identify the primary Resources page file
   - List the supporting icon, navigation, footer, root layout, and global style files
   - Clearly mark the generated route file as read-only

## Deliverable
A standalone, implementation-ready written page brief that can be handed to a designer or developer to reproduce the page accurately.
